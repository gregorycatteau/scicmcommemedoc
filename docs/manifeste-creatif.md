# Manifeste creatif

Le site raconte une maniere d habiter le Medoc.

Il doit conserver :

- chaleur ;
- matiere ;
- respiration ;
- photographie territoriale ;
- dignite ;
- sobriete ;
- progression narrative.

Il evite :

- template SaaS ;
- annuaire jaune ;
- greenwashing ;
- gamification artificielle ;
- pictogrammes enfantins ;
- effets permanents.
