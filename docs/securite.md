# Securite

- Aucune donnee frontend n est fiable.
- Les formulaires publics ne publient jamais directement.
- Les erreurs techniques ne sont pas affichees aux visiteurs.
- Les endpoints publics viennent de la configuration runtime.
- Les donnees personnelles doivent rester minimales.
- Les futures mutations de contribution doivent appliquer validation serveur, honeypot, limites de longueur, moderation et rate limiting.
