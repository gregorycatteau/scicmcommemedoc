# Vision produit

M Comme Medoc aide les habitants a reprendre prise sur les ressources, savoir-faire et liens utiles du territoire.

Le visiteur reste le protagoniste. Le site doit lui offrir une aide concrete avant de l inviter a rejoindre une dynamique collective.

Priorites :

- donner une information fiable ;
- rendre l action locale plus simple ;
- distinguer clairement donnees verifiees et demonstration ;
- ne jamais transformer le projet en annuaire publicitaire.
