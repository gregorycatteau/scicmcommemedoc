# Editorial

Le ton est humain, territorial et concret.

Regles :

- expliquer les benefices avant la structure ;
- ne pas utiliser de jargon juridique trop tot ;
- ne jamais presenter une donnee non verifiee comme un bon plan ;
- signaler les limites des estimateurs et diagnostics ;
- eviter les promesses de securite, de gain financier ou de disponibilite.
